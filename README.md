# STR Fee and ROI Calculator

Free calculators for short term rental hosts, live at https://santoshi15.github.io/str-fee-calculator/

- Fee calculator: compares Airbnb and Vrbo host fees and payouts for one stay, with discounts, cleaning and pet fees, and a booking date switch for the Vrbo fee structures before and after Oct 29, 2026.
- ROI calculator: annual revenue, platform fees, expenses, net operating income, cash flow, cap rate, and cash on cash return from the host's own inputs.

Built and run by David, host of The Square on Prairie in Sioux Falls, Superhost on Airbnb and Premier Host on Vrbo. The calculators are free. A paid listing audit is offered on the page for hosts who want their own listing reviewed.

Static site, vanilla HTML, CSS, and JavaScript. No build step. Contact: david.strtracker@gmail.com
